# Команды чата

Префикс всех команд — `!`. Реестр команд хранится в таблицах
`bot_commands` / `bot_command_aliases` и заполняется при старте бота через
`services.command_registry.register_command(...)`. Команда `!команды` читает
этот реестр и показывает только `is_active=True` и `is_visible=True`.

## Права

| Роль | Ранг | Возможности |
|---|---:|---|
| `owner` | 100 | все |
| `streamer` | 80 | всё, кроме `MANAGE_STAFF` и `MANAGE_SERVICE_BAN` |
| `admin` | 60 | `RECOMMEND`, `EDIT_TABLES`, `ADMIN_COMMANDS`, `MANAGE_EDITORS` |
| `editor` | 40 | `RECOMMEND`, `EDIT_TABLES` |
| `user` | 20 | `RECOMMEND` |

Проверки в командах идут через `resolve_actor(...)` и
`Actor.can_command(...)`; роль хранится в `users.role`. Для таймера отдельно
разрешены Twitch-модераторы.

## Пользовательские команды

| Команда | Что делает | Ограничения |
|---|---|---|
| `!игры [игра]`, `!игра` | статистика по игре и ссылка на таблицу | без аргумента — канальный кулдаун 20 с; с аргументом — 1 с на пользователя |
| `!стримы [ДД.ММ.ГГ]`, `!стрим` | информация о стриме за дату | канальный кулдаун 5 с |
| `!hltb [игра]` | время прохождения из HowLongToBeat; без аргумента — текущая игра | дедупликация одинаковых запросов 30 с |
| `!праздник` | случайный праздник на сегодня | канальный кулдаун 5 с |
| `!праздник все` | все праздники на сегодня | |
| `!праздник <номер>` | праздник по номеру из списка на сегодня | |
| `!праздник <дата>`, `!праздник <дата> <номер>` | праздники на дату `ДД-ММ` / `ДД.ММ` / `ДД/ММ` | |
| `!праздник <текст>` | поиск праздника по названию | |
| `!время` | длительность текущего стрима и категорий | канальный кулдаун 5 с; нужна активная runtime-сессия |
| `!инфо [тема]` | справка по стримеру, компьютеру, девайсам | канальный кулдаун 60 с; без аргумента — `стример` |
| `!r` | переводит текст сообщения-ответа из неправильной раскладки | только ответом на сообщение; кулдаун 3 с |
| `!команды [команда]`, `!команда`, `!помощь`, `!help` | список команд или описание одной команды | канальный кулдаун 5 с |

### Рекомендации

Команда: `!рек [игра]`.

| Форма | Действие |
|---|---|
| `!рек <игра>` | предложить игру или проголосовать за уже предложенную |
| `!рек` | показать справку по рекомендациям |
| `!рек -` | удалить свою последнюю рекомендацию |
| `!рек - <игра>` | удалить свою рекомендацию по названию |
| `!рек -- <user> [игра]` | админское удаление рекомендаций пользователя |
| `!рек + <игра>` | добавить игру от имени стримера; нужно `ADMIN_COMMANDS` |

Кулдаун — 1 с на команду в канале. У обычного пользователя не больше
`RECOMMENDATIONS_LIMIT` активных рекомендаций: при добавлении новой самая
старая удаляется. Для ролей `editor` и выше лимит не применяется. Забаненные
в Twitch пользователи не могут рекомендовать (действие имитируется как
успешное, но запись не создаётся).

### Фильм

Команда: `!фильм`; алиасы `!сериал`, `!серия`, `!кино`, `!film`, `!movie`,
`!начало`, `!сезон`, `!lost`, `!лост`.

| Форма | Действие |
|---|---|
| `!фильм` | показать текущий фильм и время |
| `!фильм + <название>` | установить фильм (нужен `ADMIN_COMMANDS`) |
| `!фильм -` | сбросить фильм (нужен `ADMIN_COMMANDS`) |
| `!фильм time` | поставить время начала «сейчас» (нужен `ADMIN_COMMANDS`) |
| `!фильм time <ЧЧ:ММ>` | задать время начала (нужен `ADMIN_COMMANDS`) |
| `!фильм - time` | убрать время (нужен `ADMIN_COMMANDS`) |

## Команды для модераторов и staff

| Команда | Доступ | Описание |
|---|---|---|
| `!таймер` | все | статус обычного таймера и таймера возврата; кулдаун 30 с |
| `!таймер <10м/1ч> [текст]` | Twitch-модератор или роль `editor`+ | запустить глобальный таймер; максимум 8 часов; новый таймер заменяет старый |
| `!таймер стоп` | Twitch-модератор или роль `editor`+ | остановить обычный таймер, затем таймер возврата |
| `!таймер возврат` | Twitch-модератор или роль `editor`+ | таймер возврата Steam на 1 ч 55 мин с алертами за час, полчаса и в момент возврата |
| `!таймер возврат стоп` | Twitch-модератор или роль `editor`+ | остановить таймер возврата |
| `!gpt <вопрос>` | `ADMIN_COMMANDS` | вопрос LLM; до 200 символов, без ссылок; кулдаун 20 с |
| `!отбой` | `ADMIN_COMMANDS` | выключить обработку команд ботом |
| `!старт` | `ADMIN_COMMANDS` | включить обработку команд ботом |

Таймер хранится в памяти процесса (`services/timer_service.py`), поэтому
сбрасывается при рестарте бота. `!отбой`/`!старт` меняют только флаг
`runtime.BOT_ENABLED`; сам процесс и подключение к Twitch не останавливаются.

## Рейды и shoutout

Команды чата не участвуют: `services/eventsub_service.py` слушает
`channel.raid.to` и `channel.shoutout.create`, после рейда при выполнении
условий отправляет shoutout и соблюдает кулдаун Twitch.

## Служебное

- Кулдауны — `utils/cooldowns.py` (`check_cooldown` — канальный,
  `check_user_cooldown` — на пользователя).
- Человекоподобные задержки ответа — `utils/delays.py`.
- Дублирование одновременных запросов — `utils/inflight.py`.
- Описания команд для `!команды` берутся из БД и синхронизируются на лист
  `БОТ` в Google Sheets через `pipeline/delivery/sheets_bot_info.py`.
- `docs/CHAT_COMMANDS.txt` — публичный текст для листа `БОТ`; при изменении
  команд обновляйте и его, иначе Google Sheets покажет устаревшую справку.
